## Опис завдання

Реалізувати обчислення подвійної суми:

```
S = Σ Σ (i O2 j) O1 C
    i=a..n  j=b..m
```

де варіант визначається через остачі від ділення номера залікової книжки:

| Параметр | Формула         | Значення | Результат          |
|----------|-----------------|----------|--------------------|
| C2       | 5103 % 2        | 1        | O1 = `-`           |
| C3       | 5103 % 3        | 0        | C = `0`            |
| C5       | 5103 % 5        | 3        | O2 = `+`           |
| C7       | 5103 % 7        | 5        | Тип i, j = `float` |

**Остаточна формула:**

```
S = Σ(i=a..n) Σ(j=b..m) [ (i + j) - 0 ]
```

де `i` та `j` мають тип `float`, результат `S` — `double`.

---

## Що і як зроблено

1. Визначено варіант завдання через остачі від ділення номера залікової книжки на 2, 3, 5 та 7.
2. Створено клас `Lab1` з методом `main`, який:
   - оголошує всі змінні (`a`, `n`, `b`, `m`, `C`, `S`) всередині методу;
   - використовує тип `float` для індексів `i` та `j` згідно з варіантом;
   - обчислює подвійну суму за формулою `S = Σ Σ (i + j) - 0`;
   - обробляє виключні ситуації: `IllegalArgumentException` (некоректні межі), `ArithmeticException` (ділення на нуль), загальний `Exception`.
3. Результат виводиться на консоль разом із параметрами варіанту.

## Результати виконання

При межах `a=1, n=5, b=1, m=5`:

```
=== Лабораторна робота №1 ===

C2=1 → O1: -
C3=0 → C = 0
C5=3 → O2: +
C7=5 → тип i,j: float
-----------------------------
a=1, n=5, b=1, m=5
S = 150.000000
```

> **Перевірка вручну:** Σ(i=1..5) Σ(j=1..5) (i+j) = Σ(i=1..5) [5i + 15] = 5·15 + 75 = 150 ✓
